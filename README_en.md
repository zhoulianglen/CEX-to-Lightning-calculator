# ⚡️BTC Lightning Network Deposit & Withdrawal Calculator

A simple and lightweight web tool to help you quickly calculate actual received amounts when using the **BTC Lightning Network** for deposits or withdrawals.  
For Chinese version: [中文文档](README.zh.md)

---

## 🔍 Overview

This tool allows users to:
- Calculate actual BTC and sats received after Lightning Network processing fees during deposits.
- Estimate Lightning invoice amount after exchange withdrawal fees.

Designed for common exchanges (Binance, OKX, Bitfinex, etc.) and personal Lightning nodes to assist in accurate transaction calculations.

## 💡 Features

- 📊 **Two Tabs Interface** — Switch easily between Deposit / Withdraw  
- ⚡ **Real-Time Calculation** — Get instant results after entering amounts and fees  
- 📋 **One-Click Copy** — Copy BTC or sats results instantly  
- 🧮 **Fully Client-Side** — 100% offline ready, no backend required  
- 🎨 **Clean & Minimal UI** — Lightweight, mobile-friendly design  

---

## 🧰 How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/zhoulianglen/CEX-to-Lightning-calculator.git
   ```
2. Open `index.html` directly in your browser — no installation needed.
