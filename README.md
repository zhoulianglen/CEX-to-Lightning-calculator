# ⚡️BTC 闪电网络充值提款计算器

一个简洁的网页工具，用于快速计算在使用 **BTC 闪电网络（Lightning Network）** 进行充值或提现时的实际到账金额。  
支持中英文切换文档：[English Version](README.md)

---

## 🔍 项目简介

本工具可帮助用户：
- 计算充值时扣除闪电网络手续费后的实际到账金额（以 BTC 与 sats 表示）。
- 计算提现时扣除交易所手续费后可收到的闪电网络票据金额。

适用于常用交易所（如 Binance、OKX、Bitfinex 等）与个人节点用户，在进行闪电通道转账、充值或提现时进行辅助计算。

## 💡 功能特性

- 📈 **双标签切换界面**：充值 / 提款 一键切换  
- ⚡ **实时计算**：输入金额与手续费即可立刻得出结果  
- 📋 **一键复制结果**：便捷复制 BTC 或 sats 值  
- 🧮 **纯前端静态实现**：无需后端，可离线使用  
- 🎨 **简洁 UI**：轻量、美观、响应式设计

## 🧰 使用方法

1. 下载仓库：
